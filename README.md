# 观澜

自选股盯盘助手。看着你放进盯盘台的 A 股，按规则给出观察、异动和风控提醒。

**仅供研究参考，不构成投资建议。** 观澜不会下单，也没有券商接口。

默认行情来自腾讯公开接口，不需要密钥。盯盘自选清单里有贵州茅台 `600519`、平安银行 `000001`、宁德时代 `300750` 等样本；选股 / 热图 / 榜单优先按成交额取沪深 A 股约 100 只（新浪），失败再回退腾讯样本池。都不是全市场。没有外网时可以把 `QUOTE_SOURCE` 改成 `mock`。

## 用 Docker Compose 启动

需要 Docker Engine 和 Docker Compose v2。

```bash
docker compose up --build
```

第一次会构建镜像并拉取 PostgreSQL、Redis。看到 api 健康之后，浏览器打开：

- 盯盘台：[http://127.0.0.1:43123](http://127.0.0.1:43123)
- 接口健康检查：[http://127.0.0.1:18080/health](http://127.0.0.1:18080/health)

页面走 43123，由 Next.js 转发到 API。数据库和 Redis 不映射到宿主机。

在 Cursor 云端 Agent 里开发时，请用编辑器的 **Ports / 端口转发** 打开 `43123`，不要直接在自己电脑浏览器里访问 `127.0.0.1`（那是你本机，不是这台 Agent）。本机自己 `docker compose up` 时，再用 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

演示库账号只在 Compose 网络里使用：用户 `guanlan`，密码 `guanlan`，库名 `guanlan`。这是本地演示口令，不要把这套服务暴露到公网。

交易时段（北京时间工作日 9:30–11:30、13:00–15:00）大约每 4 秒拉一次报价。收盘、午休和周末大约每 60 秒刷新，页面标明「已收盘，显示最近成交价」。间隔可用 `SCAN_INTERVAL_SECONDS` 和 `OFFHOURS_SCAN_INTERVAL_SECONDS` 调整，最短 3 秒。

停掉：

```bash
docker compose down
```

连数据一起清掉：

```bash
docker compose down -v
```

如果这套库是用以前的模拟价格建的，参考价仍等于演示锚点（例如茅台 `1428`）时，第一次拿到真实行情会把参考价改成现价，避免止损被旧锚点误触发。你改过的参考价会保留。想整库重来，用上面的 `docker compose down -v`。

## 顶栏与交互

## 行情从哪来

默认 `QUOTE_SOURCE=tencent`。

- 现价、昨收、开高低、涨跌幅、量比：`https://qt.gtimg.cn/q=sh600519,sz000001`，响应是 GBK。一次扫描把清单里的股票拼成一批请求。
- 大盘观察同一来源，另拉 `sh000001`（上证指数）、`sz399001`（深证成指）、`sz399006`（创业板指）。成交额用行情行里的万元字段换算。刷新跟个股扫描同一节奏：交易时段约 4 秒，非交易时段约 60 秒。接口是 `GET /api/market`。
- 涨跌家数：优先东方财富 `ulist`；失败改用新浪行情中心对沪深 A 股涨跌幅排序做全市场统计；再失败才用当前选股池估算（标明不是全市场）。
- 指数拉取失败时保留上次成功的三点，并标成延迟，不影响个股扫描和健康检查。
- 前复权日 K 和 20 日高点：`https://web.ifzq.gtimg.cn/appstock/app/fqkline/get`。日 K 不跟报价一起每几秒拉，成功后缓存数小时；个股页第一次打开会补这一只。
- 不需要 API key。这是公开网页接口，个人研究使用，请自行控制频率，不要把服务暴露到公网，也不要当成稳定的商用行情源。接口字段和可用性可能变化。
- 超时或失败时保留上一笔成功报价，打日志，API 继续服务。页面会出现「行情延迟，显示上次成功报价」。还没成功过时，用清单里的占位价并标成延迟，不据此写新告警。

规则仍是三条：上车观察、异动预警、风控提醒（页面文案是观察 / 异动 / 风控）。输入换成上述报价。

热门池、榜单、选股和首页热图优先用新浪沪深 A 股成交额榜（约两页共 100 只），量比尽量再用腾讯现价补全；行业名优先清单样本，否则按东方财富 F10 缓存补全（每轮最多补一批）。失败回退腾讯样本池。按扫描间隔缓存，失败时保留上次结果并标延迟。这不是沪深全市场。

其他公开源，失败时接口仍返回 200，页面写明缺了什么：

- 日 K、周 K、分时：腾讯 `fqkline` / `minute`。周 K 的 JSON 键是 `qfqweek`。
- 财务：东方财富主要指标 `ZYZBAjaxNew`。取不到就空表，并说明不是这只股票没有财报。
- 新闻：新浪财经滚动，要闻和股市两栏，大约缓存 60 秒。
- VIX：Yahoo Finance 的 `^VIX`。
- 财经日历：东方财富已发布的 CPI / PPI / PMI / GDP；没有稳定的前瞻日历时，后面仍附带标明「示例」的常规发布窗口。
- AI：设置 `OPENAI_API_KEY` 后请求 `OPENAI_BASE_URL`（默认 OpenAI）的 chat completions，模型默认 `gpt-4o-mini`。没密钥或调用失败时返回结构化演示报告，并标明演示。密钥不会写进日志。

付费会员和邀请码不做。KOL、暗池没有稳定公开源，只保留「暂未接入」说明。

量化回测用前复权日 K 收盘价做多，不计手续费和滑点，不会下单。

### 关掉真实行情，回到演示脉冲

```bash
QUOTE_SOURCE=mock
DEMO_AUTO_PULSE=true
```

`QUOTE_SOURCE=mock` 使用内存里的随机游走，并重新打开「模拟冲击」。`DEMO_AUTO_PULSE` 默认 `false`；只有 mock 源才会按扫描改写价格。真实行情下冲击按钮会说明如何回退，不会改写腾讯报价。

## 怎么看到新告警

交易时段里，短窗口涨跌、突破 20 日高点、量比和止损会按规则中心的阈值写入告警流。同一只股票、同一条规则在几分钟内不会重复刷屏，去重放在 Redis 里。

模拟冲击只在 `QUOTE_SOURCE=mock` 时出现在盯盘台和个股页：

- 拉升 +3.6%、回撤 -3.6%：短窗口涨跌
- 突破高点：20 日高点
- 放量：量比
- 触及止损：先在自选里，按该股止损线把价格打下去

手动模拟不受「仅交易时段」限制。自动扫描会遵守这个开关。

## 本地分开跑

适合改代码。仍然需要 Redis。数据库可以是本机 PostgreSQL，连接串见 `.env.example`。Windows 上没有 PostgreSQL 时可以用 SQLite（引擎已按方言分开，不会把 PostgreSQL 的连接池参数套上去）：

```bash
DATABASE_URL=sqlite:///./guanlan.db
```

```bash
cd api
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 18080
```

另一个终端：

```bash
cd web
npm install
API_INTERNAL_URL=http://127.0.0.1:18080 npm run dev
```

前端开发地址同样是 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

规则和行情测试（含向腾讯拉取 `600519`、`000001` 的非模拟报价）：

```bash
cd api
PYTHONPATH=. pytest -q
```

只想确认两只股票能拉到价格：

```bash
cd api
PYTHONPATH=. python -c "from app.tencent import fetch_spot; spots=fetch_spot(['600519','000001']); print(spots['600519']); print(spots['000001'])"
```

确认三大指数：

```bash
cd api
PYTHONPATH=. python -c "from app.tencent import fetch_indices; spots=fetch_indices(); print(spots['sh000001']); print(spots['sz399001']); print(spots['sz399006'])"
```

服务起来之后也可以看：

- [http://127.0.0.1:18080/api/market](http://127.0.0.1:18080/api/market) 三大指数
- [http://127.0.0.1:18080/api/pool](http://127.0.0.1:18080/api/pool) 热门池
- [http://127.0.0.1:18080/api/news?column=headline](http://127.0.0.1:18080/api/news?column=headline) 要闻
- [http://127.0.0.1:18080/api/calendar](http://127.0.0.1:18080/api/calendar) 宏观日历
- `GET /api/market` 响应里的 `breadth` 字段：涨跌家数

页面冒烟：打开首页后，顶栏从「首页」滑到「我的」，每一项都应有表格、列表或说明，而不是空白。盯盘台仍能看到自选和三大指数。告警流、规则中心保持原样。

`pytest` 会检查这些 API 路径是否注册、指标和回测、选股过滤、财务/新闻/VIX 解析、示例日历，以及 `web/app` 里对应页面文件是否存在。它不会启动数据库。真实行情用例仍会请求腾讯，确认 `600519` 和 `000001` 不是模拟价，三大指数价格非空。

## 目录

```
api/     FastAPI、规则引擎、腾讯行情、研究接口、APScheduler
```
